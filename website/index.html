GOOD TO KNOW

A few quick answers.

Does StopAlert work without an account?

Yes. Install the app and start using it without creating an account.

Will alerts work without internet?

Yes. Once you set a destination, tracking and alarms keep working offline. Map tiles show if they were already loaded.

Will alarms ring when my screen is locked?

Yes. StopAlert is designed to keep its reminders working when your phone is locked.

How do I install the Android app?

Download the APK, allow your browser or file manager to install apps, then open the file and follow the prompts.
